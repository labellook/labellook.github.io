# 대화상조 웹사이트

디자인 시안 두 개(`대화상조 웹사이트 (standalone).html`, `대화상조 모바일 (standalone).html`)를
실제 동작하는 정적 사이트로 옮긴 것입니다.

- **데스크톱** — 좌우 분할 + 사선 패널, 상단 메뉴로 페이지 전환 (데스크톱 시안 구성 유지)
- **모바일** — 화면별 사진 히어로 + 하단 전화/카톡 고정 바 (모바일 시안 구성)

## 실행

```bash
./serve.sh          # http://localhost:5173
./serve.sh 8080     # 포트 지정
```

## GitHub Pages 배포

이 폴더 전체가 곧 사이트입니다. 빌드 과정이 없습니다.

```bash
git init
git add .
git commit -m "대화상조 웹사이트"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

그 다음 저장소 **Settings → Pages** 에서
*Source* 를 `Deploy from a branch`, *Branch* 를 `main` / `/ (root)` 로 두면 됩니다.
1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

- 모든 경로가 상대경로라 저장소 하위 주소(`/<저장소>/`)에서도 그대로 동작합니다
- `.nojekyll` 이 들어 있습니다 — Jekyll이 폰트 폴더를 건드리지 않게 합니다
- 폰트 308개가 `unicode-range` 로 나뉘어 있어, 방문자는 화면에 실제로 쓰인 글자의 조각만 내려받습니다

## 구조

```
index.html                 4개 페이지가 한 파일에. 메뉴로 전환합니다
assets/css/style.css       디자인 토큰 + 데스크톱/모바일 레이아웃 (경계 900px)
assets/js/main.js          페이지 전환 · 배경 전환 · 모바일 메뉴 · 문자 링크
assets/fonts/              Nanum Myeongjo, Noto Sans KR (시안에서 추출, 전부 오프라인)
assets/img/                사진 5종
```

## 동작하는 것

- 상단 메뉴 → 홈 / 회사소개 / 상조상품 / 상담·문의 전환.
  주소창 `#about` 등으로 직접 접근·공유할 수 있고 뒤로가기도 동작합니다
- **탭을 옮기면 배경 사진도 함께 바뀝니다** — 사진 4장이 탭 4개에 하나씩 붙습니다
- 화면 높이가 낮아도(뷰포트 620px까지) 각 페이지가 스크롤 없이 한 화면에 들어갑니다
- 모바일 햄버거 → 전체화면 메뉴 시트 (Esc·바깥 버튼으로 닫힘, 열린 동안 본문 스크롤 잠금)
- 전화(`tel:`) · 카카오톡 오픈채팅 · 문자(`sms:`, 상담 요청 양식이 미리 채워진 채로 문자 앱이 열립니다)

| `plan-basic.jpg` | 무빈소 기본형 제단 | 상품 카드 |
| `plan-premium.jpg` | 무빈소 고급형 제단 | 상품 카드 |

데스크톱 배경과 모바일 히어로가 같은 배정을 씁니다.

- 배경·히어로는 **흑백이 아니라 채도 50~55%** — 촛불의 온기를 남기면서 차분함을 지킵니다
- 제단 사진은 **컬러 그대로** — 기본형(밝은 나무)과 고급형(짙은 원목·자주 꽃) 차이가 색으로 드러납니다
- 데스크톱은 사진의 좌측 39%만 보이므로 사진마다 `object-position`을 따로 잡았습니다
- 원본 PNG 5MB대 → 폭 1800 JPEG로 변환 (이미지 전체 1.3MB)

브랜드 마크는 5장 꽃잎 + 줄기 + 잎 하나를 인라인 SVG로 그렸습니다 (`currentColor`를 따릅니다).

## 디자인 정리 (시안 대비)

구성은 시안 그대로 두고, 흩어져 있던 값을 토큰 한 벌로 묶었습니다.

| | 시안 | 지금 |
|---|---|---|
| 글자색 | 11단계 | 4단계 (`--fg` ~ `--fg-4`) |
| 구분선 | `.26 / .22 / .14` 혼용 | 2단계 (`--line`, `--line-2`) |
| 폰트 크기 | 21종 | 7단계 스케일 |
| 여백 | 임의 px | 4px 배수 스케일 |

### 데스크톱에서 손댄 것

- **홈** — 각주(`*무빈소라 해도…`)를 뺐습니다. 바로 위 문장이 같은 말을 합니다.
  구분선도 뺐습니다(지표 윗선과 겹쳐 이중선으로 보였습니다). 간격을 18/46/30/58로 벌려 위계를 만들었습니다
- **상조상품** — 나란한 2열 카드. 제단 사진이 크게 들어가 두 상품이 바로 비교됩니다.
  절차는 3열 2행 표로 닫았습니다
- 지표 숫자를 명조로 — 좌측 대표번호·가격과 결을 맞췄습니다
- 상담·문의의 입력 폼은 제거했습니다. 전화·카톡·문자 세 창구만 남겼습니다
- 하단의 배경 전환 선과 고지문(`선수금 100% 보전 · 제 2024-고양-0001호 · © 2024 대화상조`)을 없앴습니다.
  이 문구는 모바일 각 화면 하단 회사 정보에는 그대로 남아 있습니다
- **낮은 화면 대응** — 사진·여백·글자가 `vh`에 따라 줄고, 800px 이하에서는
  회사소개 값 4개를 2열로 접습니다. 620~1000px 전 구간에서 스크롤이 생기지 않습니다

### 모바일 (≤900px)

- **사진과 제목을 분리** — 사진 띠 200px은 밝게 제대로 보여주고, 제목은 그 아래 어두운 면에서 또렷하게.
  홈만 시안대로 사진 히어로 540px 위에 메시지가 얹힙니다
- **좌측 정렬선 하나** — 회사소개·절차의 번호를 옆이 아니라 제목 위로 올렸습니다
- **타입 스케일** — 제목 30 / 소제목 17 / 본문 14 / 캡션 12.5 / 라벨 10.5(자간 .2em)
- **카드 한 규칙** — 홈 상품 카드와 문의 채널이 같은 옷(`--card`, `--card-b`, 패딩 18px)
- **여백 리듬** — 섹션 간 40px, 블록 내 10~16px
- **푸터 분리** — 회사 정보를 본문에서 떼어 윗선 + 여백으로 마무리
- **절차** — 원형 번호 마커를 단 2열 그리드 (세로 6줄은 화면을 너무 잡아먹었습니다)
- 상단 바: 홈은 로고 + 햄버거, 하위는 ← 뒤로 + 로고 + "24시간 상담"
- 하단 고정 바: 전화(흰) + 카카오톡(외곽선)
- 문서 전체가 자연스럽게 스크롤됩니다 (화면 안에서 또 스크롤되지 않음)
